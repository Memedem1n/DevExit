# DevExit Project Roadmap & Vision

## 🎯 Visionary Features (To Be Built)
- [x] **Watchlist (Favoriting):** Investors can save projects to track them later. (Building Now)
- [ ] **AI Valuation Engine:** Real-time valuation based on MMR and tech stack trends.
- [ ] **NDA Workflow:** Digital NDA signing before revealing sensitive project data.
- [ ] **Data Rooms:** Secure area for sharing P&L statements and code audits.
- [ ] **Investor Badges:** "Verified Buyer", "Whale", "Fast Responder" badges.
- [ ] **Project Milestones:** Sellers can post updates about growth or new features.

## 🛠️ Technical Missing Parts (Security & Stability)
- [ ] **Input Validation (Zod):** Strict validation for all API endpoints.
- [ ] **Error Boundaries:** Global React error handling.
- [ ] **Image Upload Strategy:** Integration with S3 or Cloudinary for real screenshots.
- [ ] **Rate Limiting:** Protect APIs from brute-force.
- [ ] **Notification System:** In-app and Email alerts for new offers/messages.
- [ ] **Unit & E2E Testing:** Jest and Playwright setup.

## 📈 Long-term Scalability
- [ ] **PostgreSQL Migration:** Move away from SQLite for production.
- [ ] **Real-time WebSockets:** Replace polling with Socket.io/Pusher for Chat.
- [ ] **Admin Dashboard:** Elite panel for site moderators to verify assets.
